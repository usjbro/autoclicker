# OCR AutoClicker

Modular autoclicker using OCR to detect "SHAKE" button.

## Structure
- `main.py`: Entry point
- `gui.py`: GUI logic
- `autoclicker.py`: Clicking logic
- `ocr_detector.py`: OCR detection
- `click_session.py`: Session settings
- `logger.py`: Logging setup
